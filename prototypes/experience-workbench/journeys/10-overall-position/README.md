# Journey 10 — Overall Position

**Status:** Golden Journey #8 / Design Approved

The full clickable prototype is preserved as `v1-golden.html.gz.b64`.

Restore it with:

```bash
base64 --decode v1-golden.html.gz.b64 | gzip -d > v1-golden.html
```

Then open `v1-golden.html` in a browser.

## Approved rules

- Show gross obligations with net.
- People is the default; Groups is secondary.
- Offset balances only for the same people and currency.
- Different currencies never combine silently.
- Estimates are optional and visibly approximate.
- An open issue affects only the relevant balance.
- Settle and Request remain separate journeys.

Approved September 4, 2026.
