# Manage People — Journey 09 V1

Open `v1-candidate.html`. No dependencies, account, network or real money required.

Start: Zurich Weekend → People → Jeanine. Explore shared groups and preferences; use All your people for relationship-wide balances. Demo contains member-view, two-currency, offline and recovery cases. For unknown save status, use a separate simulated service-result control; Check status must not manufacture success.

Source: `source/model.cjs` contains fixture data and guards; `source/ui.js` renders the screens; `source/people.css` contains only new scoped components. `source/inherited.css` is unchanged Golden CSS. `node source/build.mjs` creates the standalone HTML. `node source/test-model.cjs` runs model assertions. `python source/browser-tests.py` performs local Playwright click-through and screenshot QA.

Payments, requests, invite creation, own method editing and group lifecycle are labelled handoff previews, not silently implemented adjacent journeys. Approval still required before Golden freeze. Screenshots are included in the review ZIP; GitHub stores the source and exact-artifact QA records.
