# Journey 18 — Edge cases

- Notification snapshot is stale when opened.
- Group access was revoked after notification delivery.
- Personally relevant saved payment history survives only within the already-approved minimal history policy.
- Notification is read but underlying task is unresolved.
- Multiple technical/provider refreshes refer to one meaningful payment state.
- Feed is offline and saved/cached.
- Refresh/load fails.
- Activity is empty.
- Notifications are empty.
- CHF and DOT appear in the same feed but remain exact separate assets.
- Current canonical record is unavailable when a notification opens.
- Adjacent destination is only a prototype preview.
