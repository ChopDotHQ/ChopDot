# Golden Pattern — Amount Entry

Established by Journey 05 Add Expense V1.

## Purpose
Make the money value the first and clearest decision in an expense flow.

## Rules
- Currency and amount are visually dominant.
- Amount uses tabular numerals.
- Description follows directly below the amount.
- Do not surround amount entry with competing settings or technical language.
- Invalid or missing amount is explained inline.
- Preserve entered values after save or validation failure.

## Inheritance
Journey 06 Edit Expense reuses this pattern with prefilled values.
