# Golden Pattern — Expense Recovery

Established by Journey 05 Add Expense V1.

## Covered states
- Missing required details
- Invalid split total
- Possible duplicate
- Offline save
- Save failure
- Settlement lock

## Rules
- Preserve entered details after recoverable failure.
- Explain one next action.
- Duplicate detection warns without trapping the user.
- Locked expenses explain why and return to the group.
- Avoid technical error codes in the primary message.
