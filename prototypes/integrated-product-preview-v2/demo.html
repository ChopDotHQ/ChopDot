Suggested walkthroughs

  1. Start locally. Continue as guest, create a group, add people, then add an expense. Change the payer and split. Go Back, reopen, and reload before saving.
  2. Review together. Open a saved expense, correct it, and inspect its history. In test mode, use the labelled Participant fixtures to agree or raise an issue. A correction resets the affected review.
  3. Choose what to settle. From People, inspect a person’s position or a group’s items. Compare selected scope before continuing. Test controls supply external preconditions; they never execute a real payment.
  4. Explore the rest. From Home try Savings, Insights, group settings, and Import / export. Pending or unknown results stay unresolved until the specified test result is supplied.
Test controls

These controls simulate Participants, failures and external results. They are hidden in the normal preview. Existing local records remain in use; opening test mode does not replace them.

Recovered unfinished drafts

An older version kept separate guest and integrated drafts. Both are retained. Choosing a recovered draft swaps it with the current draft, which remains available here. Nothing is saved as an expense.
