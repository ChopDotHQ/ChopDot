# Polkadot host simulation proof

This packet is generated by `npm run test:host-sim` using Parity's official
`@parity/host-api-test-sdk@0.10.0`.

It proves the portable shell's Product SDK boundary can:

- obtain separate product-scoped identities for Alice and Bob;
- publish ciphertext rather than plaintext group data;
- deliver and decrypt the same group event in Bob's hosted product;
- keep a completed host payment as `observed_only`; and
- submit and retrieve a redacted receipt packet.

`report.json` is the machine-readable result. The screenshots show the two
separate host containers used by the test; the technical actions are
developer-only and never appear in normal ChopDot UI.

This is not live-network proof. Product Account login through Polkadot Mobile,
live Statement Store convergence, live payment execution, and live receipt
retrieval remain separate promotion gates.
