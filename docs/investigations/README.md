# ChopDot side investigations

Side investigations answer adjacent questions that can invalidate a proposed
implementation even when its direct tests pass. Create a dated file from
`0000-template.md`, link it from the PR, and update the affected invariant or ADR
when the conclusion changes direction.

An investigation is evidence of reasoning and experimentation. It is not
runtime, real-host, chain, user, or release proof unless it contains and binds
that evidence explicitly.
