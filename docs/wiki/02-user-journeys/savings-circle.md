# Savings Circle Journey

Savings circles extend ChopDot from one-off splits into recurring group commitments.

## Job

Members contribute to a round, the treasurer confirms what arrived, delays can be recorded, and the round closes with a record.

## Rule

The commitment kernel stays behind the product. Users see contributions, confirmations, delays, payout readiness, and saved records.
