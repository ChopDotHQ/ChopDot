# Agent Failure Modes

The wiki exists because agents can make technically valid changes that make ChopDot worse.

## Common Failures

- Starting from architecture instead of a person/job/outcome.
- Treating generated docs as current truth.
- Adding UI explanation instead of cutting scope.
- Passing selectors while failing screenshots.
- Letting native/adapter language leak into normal UI.
