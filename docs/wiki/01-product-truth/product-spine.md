# Product Spine

ChopDot should feel like:

```text
I paid / I need to collect
-> ChopDot captures the moment
-> friends get one obvious action
-> payment is marked or recorded
-> receiver confirms what arrived
-> group closes with a readable saved record
```

This page is a routing summary. `product/product-principles.md` owns the product rules.

## Use This For

- Deciding if a proposed feature fits ChopDot.
- Keeping UI centered on Catch, Management, Payout, and History.
- Rejecting chain-first or dashboard-first drift.
