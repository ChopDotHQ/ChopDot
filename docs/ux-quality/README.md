# ChopDot UX Quality Framework

This folder contains the repeatable UX review layer used while integrating the approved ChopDot journeys into one continuous product.

Start here:

1. `PROCESS.md` — when the review happens in each gate.
2. `UX_LAWS_V1.md` — the seven psychology/usability laws and ChopDot-specific interpretation.
3. `JOURNEY_UX_REVIEW_TEMPLATE.md` — repeatable review worksheet.
4. `reviews/` — completed/baseline reviews and findings.

The framework is intentionally lightweight. It is evidence-oriented, not score-oriented.

Core rule:

> Fidelity tells us whether we integrated what was approved. Continuity tells us whether the product still makes sense between journeys. UX-law review tells us whether the resulting experience is actually easy and natural to use.

None of these replaces human acceptance.
