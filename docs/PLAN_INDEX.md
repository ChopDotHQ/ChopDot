**Active mode:** Product-first execution with one obvious next action per screen  
**Update rule:** Track this file when a new decision card becomes active, or when a lane status changes.

## How to use
- **`status`**: `active`, `active-next-goal`, `local-gate-ready`, `complete-local`, `implemented-local`, `active-research`, `active-thesis`, `lab-only`, `decision-packet`, `superseded`
- **`track`**:  
  - **Track 1** = product execution (app UX, users, loops, flows)  
  - **Track 2** = stack/adapters/proof infrastructure
- **`role`**: source of truth (`executive` / `reference` / `candidate` / `evidence` / `history`)
